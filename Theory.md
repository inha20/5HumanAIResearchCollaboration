Human-AI Research Continuity Theory (HARCT) Purpose 

This document proposes a theoretical refinement of the Human-AI Research Collaboration study.

The original study identifies several important concepts:

Externalized Memory Context Transfer AI-to-AI Handover Distributed Research Memory Human-AI Working Agreements 

This document argues that these concepts can be unified under a higher-level framework:

Human-AI Research Continuity Theory (HARCT)

1. Central Claim 

The central claim of the theory is:

Long-term Human-AI collaboration is fundamentally a problem of research continuity rather than intelligence alone.

Current discussions surrounding AI often focus on reasoning capability, model performance, or context window size.

However, observations from the Minor Thesis research program suggest that long-term research success depends primarily on the ability to preserve, restore, and transfer research context across time.

Under this interpretation, intelligence is necessary but insufficient.

Research continuity becomes the primary challenge.

2. Why Research Continuity Fails 

Research continuity is threatened by multiple factors.

Human Memory Limits 

Human researchers forget details, lose track of decisions, and experience interruptions.

AI Memory Limits 

AI systems operate within finite context windows and session boundaries.

Token Constraints 

Large projects eventually exceed available processing capacity.

AI System Transitions 

Research often moves between different AI systems.

These limitations create recurring context loss.

3. Memory Repositories 

A key observation from the research program was that research context does not need to remain inside either humans or AI systems.

Instead, it can be preserved within memory repositories.

This study defines Memory Repository as:

Any artifact capable of preserving research context and supporting future context restoration.

Examples include:

GitHub repositories README files Research logs Handover documents Reminder systems Project memory systems 

Under this perspective, Externalized Memory is not merely documentation.

It is a distributed network of memory repositories.

4. Future-Self Collaboration 

One of the most distinctive observations of the research program was the emergence of Future-Self Collaboration.

A recurring pattern was observed:

Present Self ↓ Memory Repository ↓ Future Self

The researcher frequently created artifacts intended to be consumed by a future version of themselves.

Examples included:

Repository structures README documents Research summaries Reminder systems Handover files 

These artifacts reduced reconstruction costs and enabled continuity across time.

Under this interpretation, future versions of the researcher become active participants in the collaboration process.

5. Human-AI Working Agreements 

Repeated collaboration produced stable interaction protocols.

These protocols functioned as context-restoration mechanisms.

Examples include:

Discovery Triggers "또 날 위해 출력해줄 거 있어?" Preservation Triggers "저장할 거 저장해줘." Gap Detection Triggers "지금 내가 놓치고 있는 것은?" Integration Triggers "연구 프로그램 관점에서 보면?" Proposal Triggers "이건 어때?" Readiness Triggers "준비됐어?" 

These phrases evolved into procedural mechanisms supporting continuity.

They should therefore be understood as collaboration infrastructure rather than simple conversation habits.

6. Human-AI Research Continuity Theory 

The theory proposes that long-term Human-AI research becomes possible when four components interact.

Memory Repositories Context Transfer Collaboration Protocols Future-Self Collaboration 

Together these components produce Research Continuity.

Research Continuity then enables:

Long-term projects Multi-AI collaboration Repository-based research programs Distributed Research Memory 7. Revised Main Hypothesis 

The original study proposed several separate hypotheses.

HARCT proposes a unified hypothesis.

Research continuity emerges when context is preserved within memory repositories, transferred through artifacts, and restored through stable collaboration protocols across time, participants, and AI systems.

Under this framework, Externalized Memory, AI-to-AI Handover, and Distributed Research Memory become components of a larger continuity system.

The primary object of study is therefore not memory itself, but the preservation of research continuity.
