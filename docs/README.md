## Purpose

These documents were developed as independent companion frameworks alongside the main paper (`paper.md`).

Although each document has been integrated into `paper.md`, they are preserved here as standalone references for the following reasons:

- Each framework remains independently readable without requiring the full paper.
- Future extraction, separate citation, or standalone publication remains possible.
- Readers who wish to study individual frameworks in depth can do so directly.

## Note on Paper Integration

These files have been integrated into `paper.md` and should be understood as having been merged into the main paper.

They are preserved here separately so that:

1. Each framework can be extracted and used independently in the future if needed.
2. Version history and evolution of each framework remains traceable.
3. Future collaborators or AI systems can access individual frameworks without reading the full paper.

Each integrated document includes a **Paper Integration Note** at the top indicating which sections of `paper.md` correspond to its content.
