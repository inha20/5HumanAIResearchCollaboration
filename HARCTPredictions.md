HARCTPredictions.md
Purpose
A useful theory should not only explain past observations.
It should also generate predictions about future observations.
This document proposes a set of predictions derived from Human-AI Research Continuity Theory (HARCT).
If these predictions repeatedly match future observations, confidence in the theory increases.
1. Prediction Principle
HARCT proposes that:
Research continuity emerges when context is preserved, transferred, and reconstructed efficiently.
If this claim is correct, several observable consequences should appear.
2. Repository Prediction
Research programs with stronger repository infrastructure should exhibit higher continuity.
Expected observations:
Faster project recovery
Lower reconstruction cost
Easier onboarding of new AI systems
Reduced context loss
Conversely, weak repository infrastructure should increase reconstruction effort.
3. README Prediction
Repositories with high-quality README files should require less reconstruction effort than repositories with poor documentation.
Expected observations:
Good README ↓ Lower Reconstruction Cost ↓ Higher Continuity
Poor README ↓ Higher Reconstruction Cost ↓ Lower Continuity
4. Handover Prediction
AI transitions should become easier when structured handover artifacts exist.
Expected observations:
AI Transition + Handover Document ↓ Lower Context Loss
AI Transition
Handover Document ↓ Higher Context Loss
5. Future-Self Prediction
Researchers who create future-oriented artifacts should recover context more efficiently than researchers who do not.
Expected observations:
Faster project resumption
Reduced repeated work
Improved continuity across long interruptions
6. Goal Preservation Prediction
Projects with strong goal preservation mechanisms should survive longer interruptions.
Expected observations:
Goal Preserved ↓ Context Reconstructed ↓ Research Continues
Goal Lost ↓ Research Direction Lost ↓ Research Fragmentation
7. Reconstruction Cost Prediction
As research duration increases, reconstruction cost should become increasingly important.
Expected observations:
Short-Term Project ↓ Low Reconstruction Cost Importance
Long-Term Project ↓ High Reconstruction Cost Importance
8. Multi-AI Prediction
Research continuity should improve when knowledge is attached to artifacts rather than specific AI systems.
Expected observations:
Artifact-Centered Knowledge ↓ AI Replaceability ↓ Higher Continuity
AI-Centered Knowledge ↓ Dependency ↓ Lower Continuity
9. Working Agreement Prediction
Stable collaboration protocols should improve continuity.
Expected observations:
Repeated Protocols ↓ Faster Context Recovery ↓ Lower Reconstruction Cost
Examples include:
"저장할 거 저장해줘."
"또 날 위해 출력해줄 거 있어?"
"연구 프로그램 관점에서 보면?"
10. Research Program Prediction
As repositories accumulate and remain connected, isolated projects should gradually evolve into larger research programs.
Expected observations:
Independent Projects ↓ Context Preservation ↓ Relationship Discovery ↓ Research Program Emergence
11. HARCT Prediction Set
The theory predicts:
Better repositories produce higher continuity.
Better documentation reduces reconstruction cost.
Better handovers reduce context loss.
Better goal preservation increases project survival.
Better future-self communication improves recovery speed.
Better collaboration protocols reduce reconstruction effort.
Artifact-centered knowledge improves AI replaceability.
12. Falsification Conditions
HARCT would be weakened if repeated observations show:
Documentation quality has no effect on reconstruction cost.
Handover artifacts do not improve continuity.
Goal preservation does not affect long-term project survival.
Repository infrastructure does not affect recovery speed.
Such observations would require revision of the theory.
